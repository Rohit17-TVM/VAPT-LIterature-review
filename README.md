
# VAPT Project – Security Operations Focus

A streamlined demonstration of real-world Vulnerability Assessment & Penetration Testing, aligned with SOC workflows.

## Overview

This project showcases a complete security assessment performed on an organization’s public-facing website, covering:

1. Reconnaissance
2. Vulnerability Assessment

3. Penetration Testing

4. Reporting & Remediation

The objective is to demonstrate hands-on expertise in identifying risks, validating exploitability, and strengthening an organization’s security posture from a SOC perspective.

 
## Skills Demonstrated

1. Attack surface mapping & OSINT

2. Enumerating exposed services & endpoints

3. Automated + manual vulnerability discovery

4. Exploiting web application flaws

5. Validating security misconfigurations

6. Drafting professional security reports

7. Providing SOC-ready detection and remediation guidance

## Major Findings (Validated)

1. Weak / default credentials

2. SQL Injection possibilities

3. XSS (Cross-Site Scripting)

4. Sensitive file exposure

5. Broken authentication & access control flaws

6. Unrestricted file upload risks

7. Missing security headers

8. Poor session management

## Tools Used

Recon: Nmap, Gobuster, WHOIS, Shodan
VA: Nessus, Nuclei, OpenVAS, Nikto, Burp Suite
PT: Burp Suite, Hydra, Manual attack vectors
Reporting: CVSS scoring, MITRE-aligned risk mapping

## SOC-Relevant Outcomes

1. Identified exploitable weaknesses that attackers can leverage

2. Mapped vulnerabilities to actionable SOC monitoring needs

3. Provided remediation steps that improve security posture

4. Supports SIEM logging, rule tuning, and IR playbook creation
